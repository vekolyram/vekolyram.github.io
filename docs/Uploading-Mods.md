# 前置条件

Celeste 模组通常在 GameBanana 上发布，这是一个模组托管网站。你必须注册一个账号才能上传模组 - [点击此处前往注册页面 :link:](https://gamebanana.com/members/account/signup)。

为符合 Celeste 分类的规则，请确保你已具备：
- 结构正确的模组 zip 文件。如果你的模组不符合此要求，请参阅 [Mod 结构文章](https://github.com/EverestAPI/Resources/wiki/Mod-Structure)。
  - 若要在不上传的情况下提前验证你的模组结构是否正确，请访问 [maddie480 的 Mod 结构验证器 :link:](https://maddie480.ovh/celeste/mod-structure-verifier)。上传你的 zip 并按下 "Verify" 即可诊断其中的问题。
- 一张模组的封面/宣传图以及*至少两张*游戏内截图，总共三张图片。所有图片都应能代表模组的内容。

检查模组的 `everest.yaml` 中的版本字段。大多数情况下，首次发布时应为 `1.0.0`。

## 上传你的模组

1. 前往 [Celeste 分类 :link:](https://gamebanana.com/games/6460)。
2. 按下导航栏中的 Add（添加）按钮，如下所示。

![GameBanana 网站 Celeste 分类页面的图片，其中 "Add" 按钮被圈出。](https://github.com/EverestAPI/Resources/assets/173492925/5d979e22-5d9c-44c3-b177-c20481d73245)

3. 选择你模组的板块（section）。大多数时候，你会想选择 `Mod`。如果你的模组是一个 Lönn 插件或第三方程序，请选择 `Tool`。
4. 填写所有板块中的信息。GameBanana 对表单中所有字段都提供了清晰的说明——一定要阅读它们！你需要重点关注这些板块：
  - **Main（主要信息）** 用于填写关于你模组的基本信息。
    - 务必在正确的*分类（category）*中上传你的模组。例如，如果我的模组是一个独立地图，我会选择 `Standalone` 分类。
    - 在 `Body` 字段中，建议（但不是必须）提供一些信息，让玩家能更好地了解他们即将游玩的内容。例如玩法风格、草莓数量、使用的技巧、难度等。
      你应该尽量提供一些关于你的模组包含什么内容以及谁会需要它的上下文信息。
  - **Ownership（所有权）** 用于给你的贡献者署名。
    - 默认提供了一些作者群组。你可以按下垃圾桶图标移除那些不适用于你模组的群组。
    - 如果你知道贡献者的 GameBanana 用户名（你可以问他们！），在 Username 字段中输入，然后点击下拉菜单中出现的那个结果。这会把条目关联到他们的 GameBanana 账号，并在他们的个人资料上把你的模组列为一笔贡献。[例如，这里就是我被署名的模组 :link:](https://gamebanana.com/members/submissions/contributions/2979687)。
    - 在 GameBanana 上发布时，你的模组默认以 [CC BY-NC-ND 4.0 许可 :link:](https://creativecommons.org/licenses/by-nc-nd/4.0/) 发布。该许可允许分享你的模组，只要提供署名即可。它也禁止对模组进行商业使用和创作演绎作品。这个许可对大多数人来说应该没问题，但如果你愿意提供自己的许可，可以到 `License` 字段设置。
  - **Media（媒体）** 用于上传你模组的文件。
    - 在 `Screenshots` 中，上传开头提到的你的模组图片。点击并拖动左侧的 "arrows"（箭头）图标可对图片排序 - **列表中的第一张图片就是人们在 GameBanana 或 Olympus 上滚动浏览模组列表时会看到的那张，所以一定要正确排序！**
    - 如果你上传的模组 zip 的名称已存在于 GameBanana 服务器的某处，末尾会被追加一串字母。这只是网站运行方式的怪癖，不必担心。
    - 再次强调，确保你的文件排序正确。最新的版本/主文件应位于最顶部。
    - 文件上的描述字段（description）允许你写一小段话说明这个文件是什么，例如 `Latest version`。它是可选的。
    - 附上视频是推荐但非必须的。视频可以是预告片或通关/攻略视频之类的东西。

其余板块对大多数模组并不相关，但这里有一些说明：
  - 如果你想将模组设为私有或禁用评论，请前往 **Settings（设置）** 分类。将模组设为私有可以让你在全面发布之前预览页面的外观。

5. 一切填写完毕之后，按下页面最底部的 `Submit` 按钮，然后等待片刻。

跳转到"验证你的上传"部分，了解自动更新器以及如何诊断问题。

# 更新你的模组

这些说明适用于你更新了模组*内容*的情况。如果你只想更新模组的详细信息，只需执行第 3 步。

1. *增加* `everest.yaml` 文件中的版本号。这会告诉更新检查器，你的新版本确实是比先前更新版本的模组。
  - 如果增加次要版本号（第二个数字），请将补丁版本号（第三个数字）重置为零。
  - 不建议增加主版本号（第一个数字），因为它表示"破坏性变更"，如果你的模组目前被其他模组依赖，可能对更新产生不良影响。
  - 这些准则源自[语义化版本 :link:](https://semver.org/)系统。如果你想阅读关于它的技术文档，请点击链接。这不是本文必需的知识。
2. 为你的模组制作一个新的 zip 文件。确保 zip 文件直接包含你模组的内容，中间不要夹着一层文件夹；你可以通过全选 `everest.yaml` 所在层级的所有内容来实现。
3. 在 GameBanana 上，导航到你模组的页面。按下 `Edit`（编辑）按钮，如下所示。

![GameBanana 网站某模组页面的图片，其中 "Edit" 按钮被圈出。](https://github.com/EverestAPI/Resources/assets/173492925/f123c2cb-4776-4703-a08c-77b04970e567)

4. 导航到 **Media（媒体）** 板块。上传你制作的新 zip 文件 - 如有需要可对其重新排序，使它成为列表中的第一个文件。移除旧文件是可选的。
5. 按下页面最底部的 `Submit` 按钮，然后等待片刻。
6. 你的更新文件现在已上传完毕！**从这里起，其余步骤都是可选的，所以你可以安全地在这里结束。** 本指南的其余部分说明如何在 GameBanana 上发布更新日志。
7. 你应当会被重定向回你的模组页面。在描述和截图之间，会有一个 `Add Update`（添加更新）按钮。它会打开一个窗口，你可以在这里更详细地描述你对模组所做的更改。
  - **Title（标题）** 可以是你喜欢的任何内容，尽管为你的版本想一个诙谐的标题吧，比如 "The Cheese Removal Update"。
  - **Version（版本）** 应与你的 `everest.yaml` 中的版本一致。
  - **Changelog（更新日志）** 是最好玩的部分——在这里描述你做出的更改。每条目应对应一项更改，并在下拉菜单中选择更改的类型。例如 `Readjusted spike positioning for gameplay leniency`。
  - **Blurb（简介）** 允许你写一段对更新的描述。任何附加信息都应放在这里。
  - 在 **Files（文件）** 中，选择你之前上传的新文件。
  - 如果这是一次小更新，请取消勾选 **Significance（重要性）**。

![GameBanana 网站 "Add Update" 表单的图片，显示了所描述的各个字段。](https://github.com/EverestAPI/Resources/assets/173492925/f711d2b2-9a1a-426a-b8c2-e4dc7fa38c38)

8. 按下窗口底部的 `Save` 按钮以发布你的更新日志。

# 验证你的模组

本节描述更新检查器以及如何对新的上传进行故障排查。

上传/更新模组后，请给更新检查器大约 5-10 分钟来验证模组。当你的模组文件上出现 "Olympus - Everest Installer" 按钮时，就说明你的文件已被收录。这意味着你的模组现在已被列入下载镜像、更新系统以及 Olympus 中的模组浏览器。恭喜！

**如果按钮在那段时间内没有出现，说明你的模组上传出了问题，或者（更少见的情况）更新检查器当前宕机了。** Celeste Discord 服务器有一个频道会在检测到无效模组时发出通知。
1. 如果还没加入，请先加入服务器。（<https://discord.gg/celeste>）
2. 导航到 `#modding_dev` 中的 `banana-watch` 主题。[这里有一个直接链接 :link:](https://discord.com/channels/403698615446536203/1145455251495845949)。
3. 你应该会看到一条来自 "Banana Watch" 机器人的消息，其中包含指向你模组的链接和一段简短说明，描述它发现的问题。这条消息将帮助你诊断和修复模组文件中的问题。
  - 如果你遇到困难，别害怕在 modding 分类下寻求帮助！社区很友好，会很乐意帮助你。
4. 按照"更新你的模组"中的步骤重新上传修复后的 zip 文件。

# 宣传你的模组

对于初学者模组作者来说，让模组获得关注可能很困难。本节介绍众多宣传模组方法中的一种（但无疑是最简单的一种）。

[Celeste Discord 服务器 :link:](https://discord.gg/celeste) 是自我宣传你作品的主要途径。这涉及几个频道：
- `#modding_showcase` 用于上传*已完成模组*的*首发版本*。在那里发帖之前，请确保你已正确完成"上传"和"验证"中的所有步骤。写一条简短的消息，概述你的模组是什么以及它为什么可能对某些人有吸引力，并附上 GameBanana 页面的链接。
- `#modding_updates` 是你发布*近期更新的模组的更新日志*的地方。
- `#modding_wip` 不用于已完成的模组——而是可用于项目公告和对即将推出的模组的预告之类的事情。如果你想在发布前制造热度，这里就是该去的地方。请注意，每个项目每月**上限**为*2 条帖子*。

这绝不是对这些频道的完整描述——请务必*阅读频道主题和置顶消息*，以充分理解这些频道的礼仪和要求，否则你的消息有被删除的风险。如果你在构思要写什么内容时遇到困难，可以看看每个频道中已有的消息，了解一下预期内容是什么样的。

如果你想获得更多曝光度，也可以 `Publish`（发布）该消息到正在关注 Celeste Discord 的服务器中。

## 附注
你是不是在制作地图并觉得需要同行评审？查看 `#modding_general` 频道中的置顶消息，找到 *Community Playtesting Server*（社区试玩服务器）的链接。在那里你会找到相关资源，让你的地图得到第二双（也许更多双）眼睛的审视，以便在发布前打磨掉 bug 和质量问题。

上传你的模组后，你可能会在 `#modding_feedback` 频道收到一些 @提醒。这个频道专门用于分享对社区制作模组的建设性反馈——请务必保持耐心，倾听社区要说的话。
