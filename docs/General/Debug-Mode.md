启用调试模式可以让你使用游戏内隐藏的一些调试功能。你会获得一些在制作模组/地图时很有用的热键、一个调试存档，以及一个允许你到处传送的游戏内关卡查看器。

## 游戏过程中可用的按键

* F5：重新加载当前关卡
* F6：打开调试地图（“关卡编辑器”），允许你到处传送
* Ctrl+F5：重新加载整个游戏。这等同于先点击“保存并退出（Save & Quit）”，然后关闭 Celeste、再次打开它并加载存档文件。
* `.`（可在 Everest 模组选项中重新绑定）或 `~`/`` ` ``：打开调试控制台
  * 输入 `help` 可获取现有命令列表，输入 `help [command]` 可获取某条命令的帮助
  * 输入 `q` 关闭控制台

:information_source: 并非所有键盘布局都有 `~`/`` ` `` 键。大多数布局都有与 `OemTilde` 和 `Oem8` 对应的按键，但由于这种不一致性，建议使用可重新绑定的按键（默认为 `.`）。

:information_source: 原版 Celeste 使用 `F1`、`F2` 和 `F3` 来重新加载关卡内的各种资源，但在 Everest 中它们已被 `F5` 重新加载功能所取代。

## 调试存档

调试模式还能在主菜单中提供一个 `~DEBUG~` 选项：这就是调试存档。该存档适用一些特定规则：

* 默认解锁所有内容。
* 当你开始一关时，你在该关卡中收集的所有草莓都会被重置。
